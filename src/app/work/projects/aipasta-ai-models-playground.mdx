## Overview

AIPasta is an innovative AI models playground that provides users with easy access to various AI models including GPT, Claude, and other large language models through a unified, user-friendly interface.

## Key Features

- **Multi-Model Chat**: Interact with 3+ AI models simultaneously
- **Side-by-Side Comparison**: Compare responses from different models
- **Modern Dark UI**: Sleek interface with real-time backend status
- **Chat History**: Persistent conversation management

## Tech Stack

- **Frontend**: React, Next.js
- **Backend**: Node.js with OpenRouter integration
- **AI Models**: GPT-4, Claude, Open source LLMs

## Current Status

🚧 **In Active Development** - Core chat functionality complete, adding more models and features.
