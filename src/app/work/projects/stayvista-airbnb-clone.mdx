## Overview

StayVista is a comprehensive Airbnb clone built from scratch using the MERN stack. Features property listings, booking management, payment integration, and user reviews.

## Key Features

- **Property Listings**: Create & manage listings with images
- **Advanced Search**: Filter by location, price, dates, amenities
- **Booking System**: Calendar-based with real-time availability
- **Stripe Payments**: Secure payment processing
- **Reviews & Ratings**: User feedback system

## Tech Stack

- **Frontend**: React.js, Redux
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Auth**: JWT tokens
- **Payments**: Stripe API
- **Maps**: Geolocation integration
